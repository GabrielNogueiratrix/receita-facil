# Receita Fácil 🍲

Protótipo acadêmico em grupo de uma aplicação web para organizar receitas e ingredientes.

## Estado atual

- Interface navegável em HTML, CSS e JavaScript.
- Receitas locais de demonstração; colar um link do YouTube **não** analisa o vídeo real.
- Ingredientes e receitas salvos no armazenamento local do navegador (`localStorage`).
- A integração real com IA/API ainda não está implementada nesta versão.
- Telas de login/contato são demonstrativas e não fazem autenticação nem enviam mensagens.

## Como executar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências, configurar chaves ou usar banco de dados.

## Próximos passos

- Implementar integração real com IA por meio de um backend, mantendo a chave da API em variável de ambiente.
- Implementar a obtenção autorizada de transcrições para processar vídeos.
- Revisar e testar as funcionalidades e a acessibilidade.

> Projeto acadêmico em desenvolvimento. As receitas exibidas são exemplos e devem ser conferidas antes do preparo.

## 🤖 Uso de Inteligência Artificial

Durante o desenvolvimento do Receita Fácil, utilizei ferramentas de Inteligência Artificial como apoio para aprimorar determinadas partes do projeto, incluindo melhorias na interface, organização dos ingredientes, padronização das unidades de medida e aperfeiçoamento de funcionalidades existentes.

A IA foi utilizada como ferramenta de auxílio ao desenvolvimento, contribuindo para o aprendizado e para a evolução do protótipo.
